* Responsive navigation bar
* Mobile hamburger menu
* Hero section with CTA
* About section
* Services section with three cards
* Testimonials section
* Contact/CTA section
* Responsive footer
* Smooth scrolling
* Scroll reveal animations

The website has been designed to work across:

* Desktop
* Tablet
